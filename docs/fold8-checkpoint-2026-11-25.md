# Fold8対応の作業記録（2026年11月25日）

Android版はv0.1.34まで実装し、Galaxy Z Fold8へ上書きインストールしました。Now barの表示内容は[3つのUI案](design/now-bar-2026-11-25/README.md)から、1台は案1、複数台は案3を採用しました。

## 実装した内容

- カバー画面では従来の1画面、開いた画面では左右2画面に切り替えます。左右それぞれで駐車場・精算待ち・履歴を選べます。
- 下タブは画面下に置き、開いた画面では矢印で左右どちらかへ寄せられます。移動するのはタブだけで、左右の表示内容や操作対象は変わりません。タブの位置は保存します。
- タブの左右移動と選択表示にアニメーションを加え、薄いガラス調の背景とAndroid風の選択表示を組み合わせました。動きを減らすOS設定にも従います。
- ヒラギノを優先し、Androidなどヒラギノがない環境では同梱のNoto Sans JPを使います。配布ライセンスも同梱しています。
- AndroidのLive Updatesに必要な権限と昇格要求に対応しました。1台なら経過時間、複数台なら台数を渡し、精算待ちだけになったら通常の継続通知へ戻します。閉じたタイマー通知の再昇格を抑える処理も加えました。

## 確認したこと

- Webの自動テスト：51件通過。
- Webの本番ビルド：成功。
- Chrome上のAndroid相当の確認画面で、開いた縦・横画面、左右のタブ位置、位置の保存、カバー画面、ダーク表示を確認しました。サンプルデータでの確認です。
- 実機で、閉じると1画面、開くと2画面へ戻る切り替えは本人が確認済みです。
- Android通知の実機テスト：確認専用の別アプリIDで5件通過。権限、通知の昇格条件、複数台、閉じた通知の扱い、システムへの通知登録を確認しました。OSの昇格フラグも有効になりました。確認用アプリは削除済みです。
- APKに含まれるWeb資産が本番ビルドと一致し、既存APKと署名が一致することを確認しました。端末でもv0.1.31への更新と昇格通知権限の付与を確認しました。
